# Hiraoka_iT Portfolio

Готовый статический сайт-портфолио.

## Что внутри
- `index.html`
- `styles.css`
- `script.js`
- `assets/avatar.jpg`
- `assets/cursor.png`

## Как запустить локально
Просто открой `index.html` в браузере.

## Как выложить на GitHub Pages
1. Создай новый репозиторий на GitHub.
2. Загрузи туда все файлы из этой папки.
3. Открой `Settings` → `Pages`.
4. В разделе `Build and deployment` выбери:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/root`
5. Сохрани.
6. Через минуту GitHub выдаст публичную ссылку.

## Как выложить на Netlify / Vercel
Можно просто загрузить всю папку сайта как статический проект.
